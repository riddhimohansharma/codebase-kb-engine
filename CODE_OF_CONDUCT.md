# Code of Conduct

This project follows the spirit of the Contributor Covenant 2.1: be respectful, assume good faith, and keep discussion about the work.

## Expected
- Be courteous and constructive in issues and discussions.
- Report problems with reproducible steps and without personal criticism.
- Respect that the maintainer decides scope (see CONTRIBUTING.md; pull requests are not accepted).

## Not acceptable
- Harassment, insults, discrimination, threats or personal attacks.
- Publishing someone's private information.
- Posting secrets, tokens or customer code in an issue. Redact them first.

## Enforcement
The maintainer may edit, hide or delete comments and block accounts that break these rules. Report a conduct problem privately through GitHub: **Security → Report a vulnerability** on this repository, and mark it as a conduct report.
