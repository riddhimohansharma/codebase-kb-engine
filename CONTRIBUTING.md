# Contributing

This project does **not accept contributions**: no pull requests, patches or code submissions. Pull requests will be closed without review.

- **Bugs:** open an issue with steps to reproduce.
- **Security issues:** report them privately, as described in [SECURITY.md](SECURITY.md).
- **Maintainer checks** before a release: `tests/guard.test.sh`, `tests/finalize.test.sh`, `tests/docs.test.sh`, `tests/inventory.test.sh`, `claude plugin validate . --strict` and `tools/sync-spec.sh --check`.
